# Completeness Checks

## Inputs
Expected elements, Export, Core elements

## Functions

### create_completeness_table(expected, export)

Restricts patients to the ones in the export so patients which are in Expected but not Export, dont count
Handles empty values: turns a " " into "" and then NA
notna() turns missing values into False

Collapses IX: so that multiple values in multiple-choice variables only count once. .any() produces True.

For longitudinal forms, the grouping is by episode_date too 
A left join is used, so every expected element survives the merge even if there is no corresponding export row.


### add_form_presence_flag(completeness)
distinguishing completely absent forms from incomplete forms

### add_core_flag(completeness, core_elements)
identifies which expected elements belong to your predefined core-element set.

removes the numeric suffix from the URN
matches using form_id + dataelement_base_urn -> if match is found, is_core = True


### empty_expected_forms(completeness)
creates tables containing expected form instances in which nothing was filled
